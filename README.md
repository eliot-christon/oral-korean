# oral-korean

A Korean listening-comprehension trainer.

The goal is a set of small exercises that play or read out Korean audio and check
whether you understood it. The first one being built is **number recognition** - hear a
spoken Korean number, answer what you heard. More exercise types are planned over time
(dates, time, basic phrases, ...).

Text-to-speech is planned to generate the Korean audio; the exact architecture for that
hasn't been decided yet.

## Status

Early development - currently just a project scaffold.
